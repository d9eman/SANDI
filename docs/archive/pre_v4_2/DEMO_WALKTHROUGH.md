# SANDI v2 demonstration walkthrough

1. Start a guest profile and save the profile ID/recovery phrase.
2. Enter a San Diego ZIP and urgency.
3. Review the real source-linked locator/application cards. Open Feeding San Diego or the San Diego Food Bank in a new tab.
4. Continue screening. Answer household size, current CalFresh, student status, family flags, and income; use Unknown/Skip to demonstrate low-barrier behavior.
5. Open results and expand the source/rule boundary for each program.
6. Create a general food-help ticket. Direct provider referrals remain disabled until a partner opts in.
7. Log in at `/staff/login`, open Question map and Rule versions, then open the user profile to see saved answer states and reasons.
8. Log in at `/provider/login`, inspect public and restricted organizations, update an availability snapshot, and import a test partner CSV.
